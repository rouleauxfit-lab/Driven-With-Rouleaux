# Drive With Rouleaux

Ready-to-deploy Vite + React site.

## Vercel
Upload this folder/repo to Vercel.

Build settings:
- Framework: Vite
- Build command: npm run build
- Output directory: dist

## Hero Image
Put your hero image in /public/mike-photo.jpeg and change this line in src/App.jsx:

const HERO_IMAGE_URL = "/mike-photo.jpeg";
